# Reference images

Mood and direction references collected by Marcus & Clara, kept here so the
design intent travels with the code.

These are **third-party works** (photography, posters, prints and botanical
plates by their respective creators, collected from the web). They are here as
private design reference only — not licensed for reuse, not part of the app,
and not covered by this repository's LICENSE. Nothing here ships in the build.

The direction extracted from them is written up in `design/direction.md`; that
document, not this folder, is what the code follows.
